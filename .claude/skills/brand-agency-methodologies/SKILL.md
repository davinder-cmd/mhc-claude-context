# Brand & Agency Methodologies

Five studios, five non-redundant angles on product-and-brand fusion — used only when the task calls for adopting one agency's whole process, not for routine brand-consistency checks.

## How to use this skill

1. **Gate first:** confirm the task is actually "which end-to-end methodology should we borrow for this identity/rebrand effort" — not a routine "does this look on-brand" question. If it's routine, this is the wrong skill; use `visual-brand-craft` or `content-design` instead.
2. Follow `roster.md`'s "How to Use This Reference" section, which routes by the shape of the brand problem: don't-know-where-to-start (IDEO, frog), visual/identity-specific (Pentagram, Ammunition), or needs-to-work-in-product (Koto).
3. Per the source file's own caution: use these five to sharpen a point of view, not to imitate one wholesale.
