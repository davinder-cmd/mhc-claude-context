# Bucher Behavior Design

Standalone, narrow-trigger skill for one person: Amy Bucher. Pulled out of the broader `engagement-behavior` roster because that file itself marks her "⭐ primary practical reference for MHC" and says to read her first for EBB/rewards work — a stronger signal than ordinary roster inclusion.

## How to use this skill

1. Before proposing a rewards or behavior-change mechanic, check it against SDT's three needs: **Autonomy, Competence, Relatedness**. A mechanic that satisfies these survives the reward being removed; one that doesn't, collapses.
2. Read the ethics guardrail and evidence pressure-test in `roster.md` first — gamification (points/badges/streaks) is a marginal lever in health per the 2026 meta-analyses, and reminders + human contact outperform it.
3. If the task is the wider engagement-loop or learning-mastery space (habit mechanics generally, learning paths, notification timing, the Hook Model, COM-B), use `engagement-behavior` instead — this skill covers Bucher specifically, not the full domain.
