# DCP Clinical Delivery

Internal, DCP-specific knowledge — external DTx-industry names and evidence, but applied narrowly to MHC's own Digital Care Path feature, not general design practice. Distinct from the external design/UX/product voices in the other skills: this is the clinical-delivery bar for a specific MHC feature, not a broadly applicable craft roster.

## How to use this skill

1. **Order matters:** usability and human-centered design come first (`ux-usability`, `reference/review/ux-heuristics.md`). Reach for this skill *after*, to pressure-test clinical/evidence rigor — never to override a usability finding.
2. **Scope matters:** only for `projects/feature-dcp/` and its condition sub-features (depression, anxiety, back pain/MSK, diabetes). Not a general engagement or product-strategy reference — for the loop mechanics underneath a DCP, use `engagement-behavior` instead (this skill is explicitly a companion to that one, bridged by Eysenbach's Law of Attrition).
3. Follow `roster.md`'s "How to use this doc" section at the top, which routes by question type (rigor bar, delivery-at-scale model, retention measurement, cautionary tales).
