# Dunford Positioning

Standalone, narrow-trigger skill for one framework: April Dunford's positioning methodology. Pulled out of the broader `product-strategy` roster because MHC's own `CLAUDE.md` already invokes her by name for a specific job (the rebrand "piggyback, not replace" argument), not as general product-strategy precedent.

## How to use this skill

1. Positioning is strategic context, not messaging — start by defining the competitive alternatives the product is actually up against, not a features list.
2. For the "piggyback, not replace" brand-extension argument specifically: use her framework to show *why* the existing bundling should extend rather than be replaced — that's the exact fit CLAUDE.md flags.
3. If the actual task is broader product strategy (what to build, prioritization, execution planning), stop and use `product-strategy` instead — this skill is intentionally narrow.
