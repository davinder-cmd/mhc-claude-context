# Visual & Brand Craft

Two merged reference rosters — general visual design and color systems — because MHC's own files already treat them as companions (they share Josef Albers as an explicit bridge entry).

## How to use this skill

1. **Never use this to score a design.** If the task is "is this design good," go to `reference/review/_kit.md` first — conformance, accessibility, UX, art direction. This skill is for *after* a review, when you need to defend or argue a specific call with a named precedent, or when generating/extending a visual system and want the theory under the decision.
2. **Route by question type:**
   - Typography, layout, grid, hierarchy, general visual craft → `roster-visual-design.md`
   - Is a color palette perceptually/systematically sound, accessible, or clinically safe → `roster-color-systems.md`
   - Data visualization specifically → Tufte (visual-design roster) + note that a full dataviz instrument doesn't exist yet (see `_kit.md`'s gap table) — don't invent one, just cite Tufte's data-ink-ratio principle.
3. Both files end with their own "How to Use This Reference" section — follow that for the specific scenario (selecting typography, building layouts, choosing colors, defending a palette, assigning clinical/risk-band color, etc.).
4. Standalone note: **Brad Frost** (Atomic Design) is *not* in this skill — he has his own narrow skill (`frost-atomic-design`) because MHC's actual component hierarchy (`design/_index.md`) is his framework in production use, not just precedent to cite.
