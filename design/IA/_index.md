# Information Architecture

Standing reference for how content is classified, organized, and surfaced across the app. Load these when working on navigation, taxonomy, surfacing logic, notifications, or where a feature/control should live.

| Doc | Covers |
|-----|--------|
| [content-surfaces-ia.md](content-surfaces-ia.md) | Channel-agnostic content framework — content **classes** (Suggestion · In progress · Goal · Broadcast · Event) × **delivery channels**; where control lives; the home page as a worked example. |

## Conventions
- IA docs are **framework-level and app-wide** — not page specs. Page/feature specifics go in `projects/` or `outputs/`.
- When a new surface or feature is introduced, classify it against the framework rather than inventing a new model.
