Why this layout RECOMMENDED

Flat 2-column tile grid. Each tile carries an icon, a focus name, and a small pillar chip at the bottom (color-coded dot + pillar name in your secondary palette). No section headers needed — the chip does the categorization work inline.

Why it works

  • System-friendly. Just an array of {name, icon, pillar} — render order can be anything (alphabetical, recommended, mixed).
  • Pillar legibility. Color dot + pillar label gives users the same taxonomy signal without grouping rows.
  • Mixable order. You can interleave categories so users see breadth in the first scroll, instead of "all physical first."
  • Single-select feels obvious from the blue-fill + check pip on the active tile.

Notes

  • Pillar palette: Physical = spring green, Emotional = aqua blue, Career = mango, Financial = zesty green, Social = lava orange. All from your secondary/tertiary tokens.
  • Tile height is fixed (130px) so a missing pillar chip never collapses the row.
  • Order shown is suggested-first, then alphabetical within. Easy to swap for a true recommendation rank.
