What changed from v2

  • Dropped the pillar chip — with 8 single-word focuses there's no taxonomy to surface.
  • Promoted the micro-line to primary supporting copy. It tells the user what they're committing to in 2–3 words.
  • Tile name went up to 16px / bold so the focus reads as the headline.
  • Mobility relabeled to Flexibility per your call — uses Lucide's stretch-horizontal.

Notes

  • Even-count grid (4×2) reads cleaner than V2's 18-tile odd grid; no orphaned tile on the last row.
  • Selected state: blue tile fill + filled blue icon + check pip in the corner. All three reinforce the same single-select signal.
  • SVGs are inlined Lucide paths so they tint with the tile state. If you'd rather link to the CDN, swap the <svg> for <img src="https://unpkg.com/lucide-static@latest/icons/{name}.svg"/> — but you'll lose the color-on-select effect.
