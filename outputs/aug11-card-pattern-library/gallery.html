Card Pattern Library — Batch 01

Twenty medium card variants — the size that has to survive both a 3–4 up grid and a horizontal carousel. No heroes, no bare thumbnails. Captured from Mobbin and read for internal layout and information hierarchy; colour and shadow are noted only where they carry the hierarchy.

01

Image-first, caption outside

Telescope · Mobbin

Anatomy

Photo (variable aspect, masonry) → attribution chip overlaid top-left (avatar + name on a translucent scrim) → title below the image → subtitle/location in a lighter weight.

Hierarchy

The image is the whole first read. Text is deliberately small and outside the frame, so the grid scans as a wall of imagery with labels rather than a wall of cards. No border, no shadow — the photo edge is the card edge.

Where it fits

Content browse where imagery is the differentiator. Fails the moment photography is inconsistent, which makes it a stress test more than a default.

PhotoMasonryOverlay chipBorderless
02

Dense metadata stack

Etsy · Mobbin

Anatomy

Square photo (play affordance where video exists) → title clamped to one line → shop name + rating + review count on one line → price, strikethrough original, discount % → badge line.

Hierarchy

Six data points, no dividers, four type sizes. Price wins because it is the only bold dark value in the stack. It works only because every card carries the identical slot order — the eye learns the pattern once, then reads down a column.

Where it fits

The density ceiling. Useful as the counter-example when someone argues a rewards or benefits card needs "just one more line."

PhotoHigh densityPrice-ledBadge line
03

Three-zone with divided footer

Skillshare · Mobbin

Anatomy

16:9 image with a heart action overlaid top-right → avatar overlapping the bottom edge of the image → author name → title (bold) → hairline rule → footer with like count, comment count, relative date.

Hierarchy

Three zones separated by two different devices — the image edge and a rule. The overlapping avatar stitches zone 1 to zone 2 so the card doesn't read as two stacked blocks. Author sits above the title, subordinating the content to the person.

Where it fits

The cleanest reference here for a card carrying both content and social proof. The ruled footer is the reusable idea.

PhotoRuled footerAvatar overlapSocial proof
04

Full-bleed colour field

ClassDojo · Mobbin

Anatomy

Solid pastel fill, one per card → illustration bleeding off the right and top edges → title bottom-left → subtitle beneath in the same colour at lower opacity.

Hierarchy

Colour does the categorisation work a tag row would otherwise do. Text anchors bottom-left with generous space above it, so the illustration reads as background and the label as foreground despite sharing the plane. The bleed is what stops it feeling like a coloured rectangle with text on it.

Where it fits

A set of 3–5 sibling entry points. Watch the accessibility cost — dark text on mid-saturation pastels is where this pattern usually fails contrast.

IllustrationNo image containerColour = categoryEdge bleed
05

Icon in a media slot

Mistral AI · Mobbin

Anatomy

Top ~45% is a saturated fill panel with a single centred glyph → title (bold) → description clamped to 2–3 lines → generous gap → attribution in small grey.

Hierarchy

The icon occupies an image slot rather than sitting inline with the title. That one decision lets an icon card sit in the same grid as an image card without looking like a different component. The gap before the attribution does the work a divider would.

Where it fits

The answer to "we don't have photography for this." Strongest pattern in the set for icon-led content that must live next to image-led content.

IconMedia slotLine clampAttribution footer
06

Icon + icon-pair meta row

Perplexity · Mobbin

Anatomy

Rounded-square icon tile top-left on a light tint → generous vertical gap → title clamped to one line → meta row of two icon+label pairs (clock + date, lock + "Private").

Hierarchy

Almost no visual weight anywhere. The title is the only dark element. The meta row uses icons as delimiters instead of middots, which reads faster at small sizes and survives translation.

Where it fits

Quiet utility cards — saved items, collections, programs the member already owns. Deliberately un-promotional.

IconLow emphasisIcon-pair meta
07

Centred single label

Employment Hero · Mobbin

Anatomy

Thin-stroke line icon, centred, upper third → large empty middle → single centred label, one or two lines, in the brand accent.

Hierarchy

There is only one thing to read. The emptiness is the hierarchy — it signals "this is a choice, not content."

Where it fits

Pick-one moments. Also the reference for a paired "Add new" affordance card, which this screen shows sitting in the same grid.

Line iconMinimalCentredChoice, not content
08

Row card, meta right

Remote · Mobbin

Anatomy

Rounded icon tile left (~48px, tinted fill) → title (bold, one line) + description (grey, one line) centre → date right-aligned, vertically centred with the title baseline.

Hierarchy

Three columns on one row. The right-aligned date creates a scannable second column down the stack, so the list reads as a table without being one. Separation by whitespace and a hairline border, not shadow.

Where it fits

To-do / next-action stacks. Directly relevant to any "what should I do next" surface — the right column is where a status or due date goes.

IconHorizontalRight columnNext action
09

Progress in card

Whop · Mobbin

Anatomy

Brand-fill thumbnail with the product name set into it (no photo) → state badge overlaid top-left ("New lesson") → title → progress bar with the percentage as a trailing label on the same line → meta line ("1 chapter · 1 lesson").

Hierarchy

The progress bar sits above the meta line, putting state ahead of structure. Setting the % inline at the end of the track rather than above it saves a full line of height — that's the detail worth copying.

Where it fits

The closest reference here to a DCP / learning-path card. The two cards shown differ only by badge + fill state — which is how one component should flex.

Brand fillProgress barState badgeLearning path
10

Corner-ribbon state

Optimal Workshop · Mobbin

Anatomy

Dark patterned thumbnail with a centred logo + word mark → diagonal ribbon top-right reading "Complete" → title in accent colour → description at 3–4 lines.

Hierarchy

State is pushed into the corner, so it costs zero vertical space and never competes with the title. The description is unusually long for a card this size and gets away with it because no metadata competes below it.

Where it fits

Completion state across a set of equal-weight modules. Cheaper than a badge that has to be laid out.

Pattern fillCorner ribbonCompletion stateLong description
11

Media-left + author footer

Unity · Mobbin

Anatomy

16:9 image occupying the left ~45% with a small sequence badge overlaid → right side: title (bold, up to 2 lines) → meta dot-row ("Tutorial · Beginner · 5 Mins") → hairline rule → author row with small avatar + name.

Hierarchy

Title dominates because it is the largest type on the card by a wide margin. The dot-row compresses three attributes into one line. The rule separates content from provenance.

Where it fits

A carousel or vertical stack where titles run long. Horizontal cards buy two lines of title without the card getting taller.

PhotoHorizontalDot-row metaRuled footer
12

Eyebrow-led

Uxcel · Mobbin

Anatomy

Screenshot floated on a light tinted field (inset, not full-bleed) → bookmark icon overlaid top-right → ALL-CAPS type label ("EXERCISE") in small grey → title (bold) → footer line with a small glyph + source name.

Hierarchy

The eyebrow tells you what kind of thing this is before you read which thing it is — the right order when a grid mixes content types. Insetting the screenshot rather than bleeding it keeps UI imagery from looking broken at small sizes.

Where it fits

Mixed-type browse grids. The inset-on-tint treatment is the answer for any imagery that isn't photography.

ScreenshotEyebrowInset mediaSave affordance
13

Row + right-side badge

Uxcel · Mobbin

Anatomy

Rounded icon tile left → title (bold) → meta line ("Course · 6h · Beginner") → pill badge pinned right ("Popular"). Selected state: 2px accent border + accent-tinted icon.

Hierarchy

Near-flat by design — this is a queue, and every row is meant to look equally available. The accent border on one row is the only strong signal, and it is carrying "you are here."

Where it fits

Long ordered lists where one item is the current step. Calmer than giving the active item a different layout.

IconHorizontalRight badgeSelected state
14

Tag-chip footer

SuperHi · Mobbin

Anatomy

Full-bleed graphic image top → title (large, 2 lines) → description (3–4 lines) → flexible gap → row of outlined chips ("FREE", "BEGINNER", "COURSE").

Hierarchy

The title is genuinely large — close to a page heading — which is what makes this work in a carousel showing only three. Taxonomy is pushed to the bottom as chips, keeping qualifiers out of the title. Equal card heights with the chip row bottom-aligned forms a rail across the carousel.

Where it fits

The reference for chips-as-footer. Bottom-aligning the chip row is what makes an unequal-copy-length set look ordered.

IllustrationCarouselChip footerLarge title
15

Colour-coded, text-only

SuperHi · Mobbin

Anatomy

Solid colour fill, one per card → title (bold, 2 lines) → description (3–4 lines) → single outlined chip bottom-left ("RESOURCES", "EVENTS").

Hierarchy

No imagery at all, and it still reads as a designed card because the fill is doing categorisation and the chip confirms it. Text stays near-black on every fill rather than inverting, which keeps the set coherent.

Where it fits

The honest answer for content with no art budget. Pair with #14 on one page and you get a two-tier system — image cards for featured, colour cards for the long tail.

16

Centred CTA card

Zillow · Mobbin

Anatomy

Illustration on the card's own white ground (no image container, no tint) → centred title (bold) → centred body, 3 lines → outlined button, centred.

Hierarchy

Symmetrical and slow. Centring makes it read as an offer rather than content, and the outlined — not filled — button keeps three side-by-side cards from fighting each other.

Where it fits

Three-up "choose your path" rows. The restraint on the button is the lesson: three filled buttons in a row is three primary actions, which is none.

IllustrationCentredOutlined CTAThree-up
17

Title above image

Julienne · Mobbin

Anatomy

Title (2 lines) → author, both above → product image centred on a warm tinted field with room around it → footer: sale price, strikethrough original, rating + review count → filled Buy button bottom-right.

Hierarchy

Inverted. You read the name, then look at the object — the opposite of every other card here. It works because the products are books, where the title is the identity, and it makes the images read as a considered still-life row rather than a product grid.

Where it fits

Rare, but the right call when the name carries more meaning than the picture. Keep it as the argument that image-on-top isn't a law.

PhotoInverted orderTinted fieldBuy footer
18

Chip → headline → meta

Going · Mobbin

Anatomy

Filled dark chip ("Airlines") → headline (bold, 2 lines) → meta line (date · read time · arrow glyph). Image, when present, sits above the chip; the same grid runs image and no-image cards side by side.

Hierarchy

Identical text hierarchy whether or not there is an image, so the grid stays even. The trailing arrow does the affordance work without a button.

Where it fits

Editorial surfaces with partial art coverage. This is the pattern that makes a half-illustrated content set look intentional instead of incomplete.

19

Dual-action footer

Midday · Mobbin

Anatomy

Logo top-left → state badge top-right ("Installed", "Beta") → title → description, 3 lines → two equal-width outlined buttons side by side ("Details" / "Install"), footer-aligned.

Hierarchy

The card carries two actions of equal weight without either becoming primary — both outlined, both half-width. State lives in the badge, so the buttons only change label ("Install" → "Disconnect").

Where it fits

Any card where "learn more" and "do it" both need to be present. The equal-weight treatment is what keeps a grid of these from reading as a wall of CTAs.

LogoTwo actionsState badgeFooter-aligned
20

Stat card

Ferndesk · Mobbin

Anatomy

Small accent-coloured icon → large numeral → label (bold, small) → description, 2 lines grey. Three cards share one container, separated by hairline dividers rather than individually bordered, with a coloured top rule per card.

Hierarchy

Number first by size, label second by weight, description third by colour — three different devices, one per level. The shared container with dividers is the detail: it reads as one panel of related metrics rather than three competing cards.

Where it fits

Any metric row. The description line is what most stat cards omit and then need a tooltip for.

What the set says

Six devices are doing nearly all the hierarchy work across these twenty cards. They're worth naming as a vocabulary.

  1. An image slot that isn't always an image (05, 04, 15) — the top block can be a photo, a tinted icon panel, or a colour fill, and the card stays the same component.
  2. The eyebrow (12, 18) — type label above the title, for grids that mix content types.
  3. The ruled footer (03, 11, 20) — a hairline separating content from provenance or metrics.
  4. Bottom-aligned chips (14, 15) — taxonomy as a rail across a carousel, keeping qualifiers out of titles.
  5. The overlay, not the row (09, 10, 12) — state and actions placed on the media so they cost no vertical space.
  6. The right column (08, 13) — right-aligning one attribute turns a card stack into a scannable table.
