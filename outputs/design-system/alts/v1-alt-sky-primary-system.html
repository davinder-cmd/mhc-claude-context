Parallel exploration. Layer 2 — Semantic Tokens

Every token references a Layer 1 stop. UI consumes semantic tokens — never raw hex.

Backgrounds & text

background.default

→ neutral.50

Primary page surface. Warm cream sets the tone — no flat white anywhere in the product.

background.subtle

→ warm.50

Hero cards, empty states, celebratory moments. Almost imperceptibly peach.

background.inverse

→ neutral.900

Dark surfaces. Modals on top of OS dark, contrast moments, dark mode hooks.
