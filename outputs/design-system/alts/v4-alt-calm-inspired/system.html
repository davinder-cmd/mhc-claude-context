Changed
  • Container-surface scope: backgrounds-only → backgrounds + container surfaces, surface character now cool not warm (B1, cool-register revision)
  • Gradient logic: saturation/brightness → hue + saturation + brightness, used selectively as 6 featured moments (3 lighter, 3 darker), all in the indigo → blue → green slice of the wheel (B4)
  • Hues excluded from gradient + halo recipes: warm, rose, fuchsia, lavender. Lavender retained as Health Data categorical for badges/glyphs/charts only.

Locked

  • Variant-grid illustrations — one composition × N palette swaps (B3)

Why border, not wash

Pastel primary.50 wash makes sand surfaces look noisy at scale. A 2px primary.600 border is sharper, more editorial, and works on top of any module hue without color clash.

Layer 4 — Icons (calm-inspired — 5 recipes, Material Symbols Outlined)

Five reusable visual recipes. v4's three editorial recipes carry forward (R1 glyph in container, R2 outlined ring, R3 naked glyph). Two new recipes express the calm-inspired gradient logic at icon scale: R4 radial halo (concentric pastel-to-mid-tone, the Calm Health "stat tile" pattern) and R5 saturated gradient container (hue-shifted darker gradient, white glyph — used on hero / featured moments). Module identity still lives in glyph color (500 on R1–R3) or container hue family (R4 halo / R5 saturated). Material Symbols Outlined throughout.

Sizing & fill

Sizes: icon.size.sm = 20px (inline, dense), icon.size.md = 24px (default, navigation, standalone), icon.size.micro = 16px (table cells, tags only — exception use). Never 18px or 22px. Stroked = default / informational / unselected; filled = selected / active / confirmation.

Library recommendation

Material Symbols Outlined (Apache 2.0). Variable font: FILL, weight, grade, opsz axes. Stakeholder narrative

This is a sibling alt to v4. Same R2 sky-teal primary, same Clinical-Modern Distinctive tribe, same graphite-on-sand neutral architecture — but a different posture toward gradient. Where v4 treats gradient as a rare reservation (deep-primary on buyer hero only), calm-inspired treats gradient as a featured language: six selective moments, each shifting hue + saturation + brightness rather than just brightness, used to give specific surfaces atmospheric depth — all anchored in the indigo → blue → green slice of the wheel.

What's borrowed: the logic of selective hue-shifted gradient, not the source material's character. From Calm Health, the use of selective gradient as featured atmospheric depth (page-bg halos, radial stat tiles, saturated hero CTAs). From Lovi, the airy pale register and pastel category-tile pattern (R4 halo recipe). Neither is copied — both are translated onto MHC's R2 palette and discipline. The page-bg wash becomes gradient.dawn-mist; the cool container becomes gradient.cool-bloom; the dark feature becomes gradient.deep-twilight (DCP), gradient.aurora (Challenges), and gradient.tide (Rewards).

What's held from v4: ink stays graphite-neutral; module identity persists through topbar dot, glyph color, and badge; selection is still a 2px border, not a wash; the cross-cutting AI register stays indigo; sand.50 remains the global page-bg floor (so no screen reads stark). What expands: container surfaces accept cool gradient washes (B1), and gradient reaches four new surface classes (page-bg, container, data-viz scale, icon container) — all within a constrained cool palette so the system reads coherent, not noisy.

How it positions us: still the top-right corner of the digital-health landscape (clinical-modern × distinctive), but with a softer arrival. The home screen feels atmospheric rather than blank. The DCP screen carries clinical depth that signals "this is a real program," not a settings panel. The rewards milestone earns a full edge-to-edge cool celebration (ocean-depth, not warm sunset) that solid color cannot give. The risk against v4: more gradient surface area means more opportunity to drift from editorial restraint — the lockstep rule is "selective, not pervasive": six gradient moments, all cool, no more, defended against expansion.
