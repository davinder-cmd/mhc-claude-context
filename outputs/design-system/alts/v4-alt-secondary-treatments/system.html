Premise
A blue-anchored sibling to v4 that loosens editorial restraint to allow a warmer, more organic secondary palette and richer icon / illustration variety — while preserving primary blue, gradient discipline, and AI-labeling principles.
Changed
  • Re-tuned warm.* from peach / terracotta toward honey / clay / ochre (hue ~22° → ~28°; pink character pulled out of midtones)
  • Re-tuned rose.* from candy pink-coral toward dusty mauve (hue ~345° → ~355°; midtone chroma reduced)
  • Softened v4 rule #3: module-tinted card surfaces and soft-tinted icon containers permitted (sand still default)
  • Icon recipes 3 → 5 (added module-tinted soft container + module-filled solid). Material Symbols Rounded replaces Outlined — heavier, less slight
  • Illustration economy softened: variant grid + 1–2 supporting compositions (empty-state, achievement) per palette set
  • Applied moments expanded 3 → 6: Member tour (DCP · Habits · Wellbeing) + system stress tests (Buyer · AI Insight · AI→human hand-off). New gradient.handoff token introduced for the hand-off only
  • Skipped 60-30-10 weighting bar this iteration (per Delta Panel)
Locked
  • Primary stays in blue family — R2 sky-teal bridge (#2A6489 at 600); D2 not re-opened
  • Tribe = Clinical-Modern Distinctive (D1)
  • neutral.* graphite ink and sand.* warm surface — split, never crossed
  • One primary CTA color (no interactive.secondary.*)
  • Gradients only on container surfaces and primary CTAs (B4 hold)
  • Cross-cutting AI register = indigo (always, regardless of host module)
  • WCAG AA minimum; 16–20px radius default for primary components

Layer 4 — Icons (5 recipes — Material Symbols Rounded)

Five recipes (was three in v4). Two added: a module-tinted soft container for moments where category should register before the glyph does, and a module-filled solid for selected / active states. Material Symbols Rounded replaces Outlined — heavier strokes and softer terminals match the warmer, more organic secondary register.

Sizing & fill

Sizes: icon.size.sm = 20px, icon.size.md = 24px (default), icon.size.micro = 16px (table cells, tags only). Never 18px or 22px. Stroked = default / informational / unselected; filled = selected / active / confirmation.

Library recommendation

Material Symbols Rounded (Apache 2.0). Same variable-font axes (FILL, weight, grade, opsz) as Outlined; the swap is one CSS line and zero asset migration. Rounded reads less surgical and more humanist — the right register for a system that's loosened editorial restraint to allow warmer card surfaces. Default weight bumped from 400 → 500 for additional substance ("not so slight"). Phosphor (MIT) remains the credible alternative.

How the hand-off works

A designed moment, not a buried link.

  • Top zone (indigo): AI recognizes its limit out loud — "that's outside what I'd want to interpret on my own". Phase 0 §9 "AI-competent" attribute, made visible.
  • Transition (dashed primary): the gradient.handoff token (indigo.50 → primary.50) — the only place this gradient is used in the system.
  • Bottom zone (primary): a real coach with a name and a short voice in their own words — not a generic "Talk to a human" button.
  • Two CTAs: primary accepts the hand-off; ghost preserves member agency. Crisis routing remains a separate deterministic UI.

Module tour proves the secondary re-tune at applied scale: warm honey-clay reads earned-warmth, rose dusty mauve reads grounded. Stress-test row proves the system holds at three different chromatic registers — full-bleed gradient (Buyer), indigo wash (AI), and indigo→primary transition (Hand-off) — without losing the sand/graphite default.

Stakeholder narrative

This is a sibling to v4, not a successor. The locked direction holds: R2 sky-teal bridge primary, Clinical-Modern Distinctive tribe, sand-on-graphite architecture, and a single primary CTA. What this iteration tests is whether v4's editorial restraint can be loosened in two specific places — secondary palette and category surface — without losing the discipline that earned v4 its place.

Two scales were re-tuned. warm moved from peach-and-terracotta toward honey-clay-ochre — a hue shift of about six degrees, but enough to pull the pink character out of midtones and make Healthy Habits feel earned-warmth rather than cosmetic-warmth. rose moved from candy-pink-coral toward dusty mauve — Wellbeing now reads grounded rather than soft. Together, the secondary palette feels organic — the explicit ask going in.

One v4 rule is partially re-opened: module-tinted card surfaces (at the 50 stop, with the matching 100 stop as border) become a permitted variant. The discipline is "one tinted card per scroll-region maximum" — tint signals category at-a-glance; multiple tints in close proximity collapse back to the noise v4 was right to retire. Icon recipes expanded from three to five (added module-tinted soft container, module-filled solid), and the icon font swapped from Material Symbols Outlined to Rounded — heavier, more humanist, less surgical, the right register for the warmer secondary direction.

Three new applied moments were added (six total). The member tour — DCP, Healthy Habits / Rewards, Wellbeing — proves the secondary re-tune at applied scale: warm reads earned-warmth rather than peach, rose reads grounded rather than candy. The system stress-test row keeps the Buyer hero, AI Insight, and adds the AI→human hand-off — Phase 0 §9 "AI-competent" made visible. The hand-off uses a new gradient token (indigo.50 → primary.50) — its only use in the system. Crisis routing remains separately deterministic-visible.

Where this lands in the landscape: still in the top-right (distinctive + clinical-modern) corner v4 plants, still distinct from Calm/Headspace and from Personify/Sharecare/Thrive — but with a softer chromatic surface and a designed AI-to-human moment that none of the reference brands (Withings, Sword, Hinge) have yet built. If this branch is promoted, the v4 editorial-restraint document would need an amended rule #3 ("Color is an accent — and may live softly on a single category surface per region") and a new §10 entry for the hand-off pattern. If not promoted, this stays in alts/ as the documented secondary-treatments fork.
