Layer 4 — Icon Treatments

Five reusable visual treatments for large category / feature / message-type icons. Each treatment is a recipe — apply any glyph, swap any categorical hue, and the icon inherits the treatment's semantic role. Combined with the 5 categorical hues (primary / warm / moss / sky / rose), this gives 25 distinct icon styles before you draw a single bespoke glyph.

How to read the rows: the leftmost column names the treatment and its semantic role. The 5 cells to the right show the same glyph and treatment recoloured across 5 categorical hues. To deploy: pick a treatment for the role, pick a hue for the module, drop in any line glyph from the icon library.

1. Solid Disc Filled circle, dark glyph centred. The everyday treatment. Use for: default category icons, dense lists, navigation, list-row leading icons.

How treatment + hue + glyph maps to your taxonomy:
  • Message types — by-feature messages use solid disc in the feature's hue · employer messages use halo in sky · challenge messages use halo in warm
  • Action types — Read / Watch / Learn / Complete / Act all use squircle; the glyph differentiates verb, the hue differentiates the originating module
  • Assessment question types — multiple-choice / scale / free-text use outlined ring in lavender or primary (low visual weight, content is the point)
  • States that overlay a category — completed / in-progress / achieved use duotone wedge, inheriting the originating category's hue
Sizing: 80px is the demo size. The treatments scale across 40 / 48 / 56 / 64 / 72 / 80 / 90 / 128 — the same range your existing icon kit defines. Stroke widths and glyph proportions stay constant; only the container scales.

Style demo — expressive register

One composition, re-tinted across four module palettes. The figure, plant, leaves, wave, and cloud are identical in every tile — only the surface, body fill, and accent stops change. This is the Withings-style illustration economy: one bespoke scene serves the whole product because the system's category hues do the variation work.

Warm-led — Healthy Habits, Activity, Challenges Surface warm.100 · body primary.400 · accent leaves moss.300/400 · emphasis primary.500
Moss-led — DCP, Care Paths, Clinical Surface moss.100 · body moss.500 · warm-300 leaf for human warmth · emphasis warm.500 (warm pop on cool field)
Sky-led — Journeys, Onboarding Surface sky.100 · body sky.400 · primary teal emphasis dot ties back to brand spine · warm-300 skin keeps it human
Rose-led — Mental Wellbeing, Wellness moments Surface rose.100 · body rose.400 · primary-500 emphasis stays as brand thread · pairs especially well with cycle, sleep, mindfulness flows
How this works in practice: illustrators draw the bespoke composition once. To deploy it inside any module, swap four token references — surface, cloud, wave, and figure body — and the same scene reads as that module's. Skin tone (warm.300), hair (neutral.900), and decorative greenery stay constant across variants so the human element doesn't drift.
Off-limits in illustration: all error.*, all warning.*, neutral.800+, sharp geometric fills, cold blues, overtly medical imagery.
