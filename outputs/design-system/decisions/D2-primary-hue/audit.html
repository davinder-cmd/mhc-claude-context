7. Verification gates — before D2 → fully LOCKED

Direction is locked. Full lock requires passing all five gates below. Any failure routes to R1 or R3 (whichever the failure mode points to).

1
Render-test on physical device

sRGB-calibrated phone, daylight, real ambient. Mineral-blue can shift up to 8% lightness on AMOLED vs. monitor. Verify 600/700 CTA still passes AA at device-render.

2
Low-light stress test (11pm member scenario)

Open the DCP card with screen brightness 20–30%. Confirm primary.600 CTA still reads as "tap me" not "decorative." Confirm primary.900 doesn't go murky on warm-temperature ambient.

3
Tactical review with Isabel (Visual Designer)

Get a tactical opinion before stakeholder review. Specifically: do the 200/300/400 stops feel useful for icons and illustrations, or do they need a chroma adjustment?

4
Buyer hero gradient at presentation scale

Render the buyer hero at 1920×1080 (board deck full-bleed). Confirm the 700→900 gradient doesn't band, doesn't feel flat, and reads premium-clinical at scale.

5
Stakeholder reaction check (Darcy, Alex)

One-line reaction: does R2 read as descended from the corporate brand, or does it still feel like a departure? If departure — pivot to R1 (more aqua DNA visible).

8. Recommendation summary + next iteration

Direction: R2 Sky-teal bridge — locked. Full lock pending verification.

R2 holds all five Phase 0 attributes, descends recognizably from both legacy anchors, sits in the least-occupied position in the B2B-health visual landscape, and is the most literal interpretation of the original D2 directive. R1 and R3 documented as alts for the verification-failure routes.

What's still open after this lock

  • Categorical hues — 4–6 module-identity colors. R1 and R3's palettes can host two of these (e.g., Health Data → R1 teal; Wearables → R3 deep blue) if direction holds at full lock.
  • Warm accent integration — confirm the warm.500 terracotta still reads as "warmth at the brand level" against R2 primary. Test in the rewards / achievement moment.
  • Categorical scale construction — the v2 build doc requires non-overlapping categorical hues. With R2 occupying the 200° slot, categorical hues need to spread across the wheel without crowding.
  • AI-surface treatment — Phase 0 §9 canonical AI moment treatment. R2's deep stops support it but the treatment itself is not yet designed.
  • Typography lock — pending budget conversation.

Next iteration target

Once R2 passes verification gates, the next iteration extends Layer 1 (full core scales) and Layer 2 (semantic tokens + gradient utility tokens) per the v2 build doc, with R2 as the locked primary. Output: complete palette preview + 3 pilot screens (member moment, buyer moment, AI moment) with weighting visualization on each.
