What's still open after Layer 3 v1

  • Progress steps component — used in pilot but not yet a token-spec'd component. Promote in v2.
  • Tooltip / popover — not yet specified. Required for "Why this?" reasoning surface (Phase 0 §9).
  • Inline alerts — semantic banner using status tokens. Required before DCP completion screens ship.
  • Toast / snackbar — not yet specified.
  • Modals + bottom sheets — radius.lg specified, full component pattern not yet.
  • Form fields — input field shown in focus demo but full spec (label, helper text, error state) deferred.
  • Avatars — not yet specified.
  • Tabs / segmented control — not yet specified.
  • Empty states — not yet specified.
  • Layer 4 — icon system — 5 treatment recipes, module-tinted icons, Material Symbols Rounded recommendation.
  • Layer 5 — illustration palette — color range, style direction, variant grid.

Next iteration target

Highest-leverage next moves: (1) Layer 4 icon system — needed for any further pilot screen to feel system-coherent. (2) Form field full spec — required for DCP onboarding completion. (3) Inline alert + toast — required for safety/error patterns.
