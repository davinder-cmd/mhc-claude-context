v4 components · editorial restraint

Components, redrawn under the v4 discipline

The original Layer 3 spec leaned on pastel 100 backgrounds throughout — badge fills, selected-state washes, radius demo cards. v4 retires all of them. Color appears as borders, dots, and labels — never as a wash. The result reads enterprise-editorial; the original read wellness-app.

What v4 removes from the components

  • Pastel badge backgrounds — variant.100 + variant.700 label is gone
  • Pastel selected-state wash — selection cards no longer use primary.50 on selected
  • Pastel radius demo cards — the primary.100 blocks were a tutorial choice, not a system rule, but felt loud
  • Ghost-button hover wash — primary.50 bg on hover replaced by underline + color shift

What v4 introduces

  • Dot + caps badges — Linear-coded status indicators. No background, just color.
  • Outline badges — for when a contained shape is required (chip in a list)
  • Border-only selected state — selection differentiation is a 2px primary border, no pastel surface
  • Underline ghost hover — text-decoration shift instead of background fill
  • Sand radius demo — same demo, neutral colors, no system shouting

Badges — dot + caps (editorial)

The biggest v4 change. The old badge pattern (variant.100 filled background + variant.700 label) was a wellness-app default. v4 uses dot + caps: a colored dot, the label in caps, no background. Reads as a status indicator on Linear / Notion / Stripe — premium-clinical, not wellness-lifestyle.
