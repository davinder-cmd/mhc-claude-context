v4 icons · 3 recipes · Material Outlined

Icon system, redrawn under v4

Layer 4 originally specified 5 treatment recipes (solid disc, soft squircle, halo, outlined ring, duotone wedge) and recommended Material Symbols Rounded. Three of the recipes leaned on pastel 100 backgrounds. v4 retires those. The recipe count drops to 3, the recommended typeface variant shifts to Outlined, and the system gets smaller and more disciplined.

Removed under v4

  • Solid disc — heavy 700 fill on a 56×56 disc. Read as a shouting affordance, not an icon.
  • Soft squircle — variant.100 pastel fill + variant.700 glyph. The squicle was the v1–v3 default; it carried the wellness-app feel.
  • Halo — 100 fill + 200 halo ring. Pastel-on-pastel.
  • Duotone wedge — split-color squircle. Loud and decorative; nothing the brand needed it to do.
  • Material Rounded as default — soft cap-rounded geometry was a v1–v3 "warmth-everywhere" choice. v4 drops the warmth-coat in favor of editorial restraint.

What v4 introduces

  • 3 treatment recipes (down from 5) — cover every use case without repetition
  • Material Symbols Outlined as the new default — more even-stroked, more editorial register, same library breadth and free license
  • Module identity = glyph color, not container fill (architectural rule from v4-canonical applied to icons)
  • Filled-vs-stroked rule preserved — variable font axis still toggles state (selected = fill 1, default = fill 0)

Filled vs. stroked

Default state = stroked. Selected/active state = filled. Same icon, different state — flipped via the variable font's FILL axis (0 → 1).

Stroked (FILL 0)

home favorite notifications person bookmark
Default state. Informational, navigation, unselected, secondary CTAs. Always stroked unless the icon is in an active state.

Filled (FILL 1)

home favorite notifications person bookmark
Selected, active, current step, confirmed. Tab bars, toggles, and selected list items get filled — the same icon stays stroked when unselected.

Three treatment recipes (down from five)

Every icon in the system uses one of these three. Pick by role, not by aesthetic.

Recipe 01
Glyph in uniform container
monitor_heart medical_information favorite smoking_rooms
Sand-100 36×36 squircle. Glyph at module's 500–700 stop. Module identity carried by glyph color, never container fill.
Use for: list-row leading icons, settings, navigation, default category markers.
Recipe 02
Outlined ring
circle check_circle radio_button_unchecked trending_up
Transparent 36px circle with 1.5px neutral.300 stroke (default) or 2px primary.600 stroke (active). Glyph stroked default, filled active.
Use for: progression markers, sequenced incomplete states, ghost affordances, "currently in progress" indicators.
Recipe 03
Naked glyph
arrow_forward close check auto_awesome
Just the glyph. Sized 16–24px. Color from semantic token or inherited from text. No container, no border.
Use for: inline icons in body text, chevrons, close affordances, status indicators inside badges, AI markers inside tags.

Rule for picking the recipe: if it's part of a list-row category, use Recipe 01. If it's a state indicator (progress, selection), use Recipe 02. Everything else — chevrons, inline, status — uses Recipe 03. Three recipes cover every product moment. The decorative-emphasis recipes (solid disc, halo, duotone) had no role at v4 restraint.

Recommended typeface — Material Symbols Outlined

Original spec recommended Material Symbols Rounded. v4 shifts to Material Symbols Outlined.

Material Symbols Rounded (was: v1–v3 default)

Soft cap-rounded geometry · 3,300+ glyphs · Free, Apache 2.0
favorite monitor_heart trending_up person notifications
Soft, friendly, organic. Was a fit for v1–v3's "warmth-everywhere" approach. Reads slightly wellness-app at v4 restraint — the cap-rounded terminals soften the editorial discipline we're trying to hold elsewhere.

Material Symbols Outlined Recommended for v4

Even-stroked, geometric · Same 3,300+ glyphs · Same Apache 2.0 license · Same variable font axes
favorite monitor_heart trending_up person notifications
More even-stroked, more editorial. Same library, same license, same variable axes — switching from Rounded to Outlined is a one-line CSS change. Reads premium-clinical at v4 restraint without losing any practical advantage. Used by Linear, Notion, Stripe-adjacent products.

What's still open after v4 icons

  • Custom icons for AI moments — Material Symbols has auto_awesome and spark, but a brand-distinct AI mark might be worth commissioning (Phase 0 §9 deliverable could extend here)
  • App icon / tab bar identity — separate territory; the launcher icon is a brand mark question, not an icon system question
  • Health-condition-specific glyphs — e.g., DCP module icons. Material covers most; a few may need custom (e.g., specific musculoskeletal anatomy)
  • Animated icons — Material doesn't ship animations. If we want micro-interactions (a heart that pulses, a check that draws on), that's a Lottie or custom SVG project

Next iteration target

If v4 icons land, Layer 5 (illustration palette) is the natural next move — and the v4 restraint discipline will likely simplify the variant grid too (Withings illustration economy stays, but the per-module palette swaps probably tone down to two or three palettes, not all six).
