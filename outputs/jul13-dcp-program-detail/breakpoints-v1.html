Colour weighting (60 / 30 / 10)

60% · warm beige ground + white surfaces 30% · graphite ink 10% · navy brand

Warm tones stay on backgrounds only; text and borders are near-neutral graphite. Navy (10%) carries the one primary CTA, the current-session dot, the progress fill and links. The reward is deliberately not in the accent budget — it's a muted graphite line, so money never dominates a clinical surface.

What's deliberately NOT here

Full health metrics → the Tracker (one outcome insight is enough here). "Learn more" / resources → in-lesson + Anna. The test for anything proposed for this page: "Does it help them start the next session?" (topic-page scope decision, feature-ebb _decisions.md.)

Rejected alternatives

  • Two-button fork (Continue + Browse) in the hero — rejected. Splits the one action into a decision (Hick's). Continue is the single dominant CTA; browse lives on the list surface.
  • Reward as a headline / repeated $100 / countdown — rejected. Violates the efficacy guardrail (racing chases the reward and gets little clinical benefit). Money is loud only on the Rewards page, never here.
  • 2-column layout at ~1040 — rejected for v1. In the legacy side-nav era usable width is ~940–1040; a 2-col split there crowds. The wider stack is calmer and the 2-col is reserved for the ≥1200 target.
  • Full 10-session list inline — rejected (Miller's). Windowed + "See all 10" keeps the path scannable.
  • Phone-in-a-frame mock as the artifact (the EBB house style) — rejected. The kit ships a real responsive system; building the live page proves the from-home continuity and the responsive logic, which a static phone mock cannot.

State matrix — next iterations

The 11-state matrix (jul07-ebb-topic-states) still to re-skin: not-started/zero (hero shows "Start the program" → routes to opt-in), final-stretch (🏁 finish marker caps the path), completed, next-session-locked (pacing gate), reward-at-risk, not-opted-in (earn-gate), cap-reached, needs-support (check-in → Anna/coach doorway), check-in-due, welcome-back.
