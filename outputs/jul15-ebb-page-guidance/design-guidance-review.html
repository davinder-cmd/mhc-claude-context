Page layout & card treatment

Guidance marked directly on the screens. The rules below are global — they apply to every DCP page. New screens are added as blocks as they come in.

Global rules (all pages)

Container width: min 720dp — don't let content float narrow/centered.
Card treatment: one style everywhere — stroke (border), not drop shadow.
Card padding: equal on all sides, top = bottom — 16 mobile / 24 desktop.
Section titles: one class — H6, 20dp mobile / 25dp desktop (e.g. "Health Data", "You may also like").
Title → section content: 20 mobile / 24 desktop.
Between modules: 16 mobile / 24 desktop.
Progress container: 40dp of space above it and between it and neighbors.
Section headers: consistent top spacing above every section title (e.g. "Ongoing", "Discover").
Breadcrumbs: desktop only — hidden on mobile (bottom nav + top-nav back arrow). Desktop breadcrumb→title: use the topic-home page as the reference.
Alignment: every section shares the same left/right container edges.
Hero buttons: horizontal, 8dp gap, equal width.
Button labels: vertically centered — no extra space below the text.
