Notes & flags

• Buttons: only the text-link (a.btn.btn-text) is authorable in a block. Filled/outlined action buttons are host-injected (mutating actions).
• Chip type is hardcoded 11sp uppercase — align to a token when theming lands.
• Progress inline --p may be stripped by CKEditor sanitizers — verify (handoff config #4).
• Stretched-link is prototype-grade: production needs keyboard focus styling + aria-hidden on duplicated content. Always the last child; parent must be position:relative.
