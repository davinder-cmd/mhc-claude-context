Notes & flags

• Type families follow Apple's 20pt optical rule: <20sp uses SF Pro Text, ≥20sp uses SF Pro Display. Classes that reach 20sp at ≥1200 flip family automatically.
• Warmth rule: warm beige lives only on backgrounds (--bg, --surface-tinted); text and borders use near-neutral graphite (--ink, --hairline), never brown.
• Deferred: theming and any token restructure. Treat these values as fixed for now; components bind to the token names, so a later theme swap is a values-only change.
