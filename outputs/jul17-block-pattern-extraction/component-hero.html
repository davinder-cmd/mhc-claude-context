Image crop & scale (the locked behaviour)

The geometry is the win: the media cell has a deterministic shape at every breakpoint, so any photo drops in and crops-to-cover predictably. Compact locks a 216px-tall band; Medium+ fills a 360px-tall column at 5/12 of the card width. No layout shift from image dimensions.

Compact media: height:216px, full width Medium+ media: height:100% of 360px cell Sibling patterns: program 16:9 · pair thumb 4:3 @≥1200

Markup

The dynamic image URL is the one inline style allowed in a block. The Medium+ CTA is not in the block — the host injects it from the state flags below; Compact relies on the stretched-link.

block-1-greeting-hero.html → CKEditor · tokenised

  <div class="hero__media" style="background-image: url('{{formula.hero_image_url}}')" aria-hidden="true"></div>

Notes & flags

• Media background-size: the locked CSS sets no background-size on .hero__media (v81 used flat tint placeholders). To display real photos, add background-size:cover; background-position:center to the media shells — recommended addition, applied demo-only here.
• CTA is host-injected on Medium+ (MHC action, mutating "Start"). The demo button is illustrative; the block never emits it.
• Stretched-link is prototype-grade — production needs keyboard focus styling on the link and aria-hidden on the card content it duplicates.
• Single-instance: documented from one source page. Variant behaviour (no-image, longer copy, different CTA states) is inferred, not sourced — needs more pages to confirm.
