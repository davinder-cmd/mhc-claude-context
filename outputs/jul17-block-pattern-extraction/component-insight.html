Insight banner

A tinted, full-width banner for an AI-generated insight — icon badge, eyebrow label with a dot, body paragraph, optional cooldown meta. State-flag driven: the host attaches the action button (Get insight / Refresh) after the block; the block only exposes which state it's in.

03

States

Mutually exclusive and exhaustive. The block renders the content for its state; the host reads the flag and attaches the matching action button.

insightsState_ready → host: "Get insight" insightsState_refreshable → host: "Refresh" insightsState_readOnly → no button / cooldown chip insightsState_hidden → zero markup
04

Markup

The whole block wraps in an inverse "hidden" conditional so the suppress case emits nothing. The action button is not here — the host injects it into the .insight__action slot from the state flags.

block-4-insights.html → CKEditor · tokenised
{{^formula.insightsState_hidden}}
<div class="insight">
  <div class="banner-icon banner-icon--insight">

Notes & flags

• Shares the banner-icon atom with the Challenge banner (.banner-icon--insight vs --challenge).
• Single-instance: the refreshable state is the only one rendered in v81; other states are documented from the block comments, not sourced.
• Action seam: keep this block in its own file — the host splices the button after it; bundling with a neighbour loses the splice point.
