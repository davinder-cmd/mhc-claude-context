Notes & flags

• The grid owns the gap and columns — cards never set their own width or margins.
• Carousel uses overflow-x:auto; scroll-snap-type:x mandatory with 78% columns and negative page margins to bleed to the edges. No JS.
• Adding a new collection? Reuse an existing grid class rather than minting a new column rule, so spacing stays identical.
