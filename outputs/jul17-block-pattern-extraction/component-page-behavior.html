03

Rhythm & grouping

• .section — 40dp (--s-07) top margin between top-level sections. Every listy block wraps in one.
• .recommendations — the supergroup that clusters hero + pair at a tighter 16→24dp gap, then still takes the 40dp section gap to whatever sits below.
• .section-head — the title + trailing-link row inside a section (see Rows).

Breakpoint engine

Viewport media queries, four Material 3 window classes. Full per-component behavior in BREAKPOINTS.md.

thresholds
Compact       < 600px      base (mobile-first) + a few max-width:599 teardowns
