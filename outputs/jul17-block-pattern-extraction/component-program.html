Markup

One program card (the repeatable unit), gated by hasProgram1. Unroll one per program (max 3) — no loops. Progress % rides a --p custom property, not a hard-coded width.

block-5-programs.html → CKEditor · tokenised
<div class="programs">
  {{#formula.hasProgram1}}
  <article class="program">
    <div class="program__media" style="background-image: url('{{formula.program1_media_url}}')" aria-hidden="true"></div>
    <div class="program__body">
      <div class="eyebrow program__tag"><span class="dot" aria-hidden="true"></span>{{formula.copy_program1_eyebrow}}</div>
      <h3 class="title-1">{{formula.copy_program1_title}}</h3>
      <div class="program__footer body-3">
        <span>{{formula.copy_program1_progress}}</span>
        <span class="price">{{formula.copy_program1_price}}</span>
      </div>
      <div class="progress"><div class="progress__fill" style="--p:{{formula.program1_progress_pct}}%"></div></div>
    </div>
    <a class="program__link" href="{{formula.program1_href}}">
      <span class="mhc-visually-hidden">{{formula.copy_program1_title}}</span>
    </a>
  </article>
  {{/formula.hasProgram1}}
  <!-- repeat program2 / program3, gated by hasProgram2 / hasProgram3 -->
</div>

Notes & flags

• Media: .program__media is aspect-ratio:16/9, fluid width — needs background-size:cover added to the locked CSS for real photos (applied demo-only here).
• Progress bar: width is var(--p) set inline per card. Confirm CKEditor doesn't strip custom-property inline styles (handoff config check #4).
• Carousel is CSS-only (overflow-x:auto; scroll-snap-type) — no JS, CKEditor-safe.
• Resume vs navigate: the card is a stretched-link (navigation). If "resume" mutates server state, each card becomes its own User Input block.
