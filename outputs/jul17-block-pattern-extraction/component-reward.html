Reward card

A reward with a coloured category chip, a large value, and two meta lines. Packs 2-up on phones and 4-up from tablet width. Four chip colourways: gift, points, raffle, store.

Variants — chip colourways

.reward-chip--gift — green .reward-chip--points — periwinkle .reward-chip--raffle — sage .reward-chip--store — peach

The chip modifier is driven by a token (reward1_chip_modifier → "gift" / "points" / …). The chip's uppercase 11sp treatment is a component-level style, not an atomic Label tier — flagged for token alignment later.

Markup

One reward card, gated by hasReward1. Unroll one per reward (max 4).

<div class="rewards">
  {{#formula.hasReward1}}

  <!-- repeat reward2 / reward3 / reward4 -->

Notes & flags

• Grid: .rewards is repeat(2,1fr) → repeat(4,1fr) at ≥600px.
• Redeem vs navigate: cards are stretched-links (navigation). If redemption mutates state on tap, each card becomes a User Input block.
• Chip type: hardcoded 11sp uppercase — align to a token when theming lands.
