  <div class="pair-card__thumb" style="background-image: url('{{formula.thumb_url}}')" aria-hidden="true"></div>
  <div class="pair-card__row-body">

    <div class="body-3 ink-soft">{{formula.copy_meta}}</div>
  </div>
</div>

<div class="greeting">
  <h1 class="heading-4"><span class="greet-compact">{{formula.copy_greeting_compact}}</span><span class="greet-medium">{{formula.copy_greeting_medium}}</span></h1>
  <div class="greeting__actions">
    <a class="icon-btn icon-btn--filled" href="{{formula.messages_href}}" aria-label="Messages"><span class="material-symbols-outlined" aria-hidden="true">mail_outline</span></a>
  </div>
</div>

Notes & flags

• Section head baseline-aligns the title and trailing link; the trailing link is always a text-link (<a>), never a button.
• Greeting copy swap uses .greet-compact / .greet-medium — author both; CSS shows one per breakpoint.
• Media row is the reusable list-row primitive — the same shape inside pair cards works for any thumb + title/meta list.
