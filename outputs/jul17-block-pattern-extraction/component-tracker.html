Tracker tile

A single health metric — icon, label, value with trend arrow, and a supporting meta line. Sits in a responsive grid that packs 2-up on phones and 4-up from tablet width. Four accent variants plus a link/zero state.

Markup

The grid wrapper plus one tile (the repeatable unit, shown with its data / zero-state pair). Unroll one tile per tracker — no loops. This is the tokenised block you paste into CKEditor; styling lives in mhc-home.css (CodeMirror).

block-3-thisweek.html → CKEditor · tokenised
<div class="trackers">

  <div class="tracker">
    {{#formula.hasLinkedTracker_steps}}
    <div class="tracker__icon">
      <span class="material-symbols-outlined" aria-hidden="true">directions_walk</span>
    </div>
    <div class="eyebrow tracker__label">{{formula.copy_tracker_steps_label}}</div>
    <div class="heading-6 tracker__value">
      <span class="arrow material-symbols-outlined" aria-hidden="true">north_east</span>
      {{formula.tracker_steps_value}}
    </div>

    <a class="program__link" href="{{formula.tracker_steps_href}}">
      <span class="mhc-visually-hidden">{{formula.copy_tracker_steps_label}}</span>
    </a>
    {{/formula.hasLinkedTracker_steps}}
    {{^formula.hasLinkedTracker_steps}}
    <div class="tracker__icon"><span class="material-symbols-outlined" aria-hidden="true">add</span></div>
    <div class="eyebrow tracker__label">{{formula.copy_tracker_steps_label}}</div>

  <!-- repeat for sleep / calories / active, adding --sleep etc. -->

</div>

Notes & flags

• Grid: .trackers is grid-template-columns: repeat(2,1fr), becoming repeat(4,1fr) at ≥600px.
• Trend arrow is a static north_east glyph in v81 — add a tracker_*_trend flag if up/down/flat should vary.
• The tile reuses .program__link for its stretched anchor rather than a dedicated .tracker__link. Intentional reuse, flagged for a naming decision.
• Zero state renders today from the base tile (add icon + link CTA, no value). A .tracker--zero modifier is named in the block comments but does not exist in mhc-home.css yet — not fabricated here.
