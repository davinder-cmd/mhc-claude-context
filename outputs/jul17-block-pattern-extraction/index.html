Component Kit

Copy-and-go building blocks for composing MHC pages — cards, rows, lists, heroes, and the page behavior underneath them. Organized like the Material 3 kit (component type → variants → responsive), each piece is complete and self-contained: grab the snippet, drop it into a page, and the containers, type, spacing, grids, and layout are already consistent. One shared stylesheet (mhc-home.css, edited in CodeMirror) drives all of it.

Copy-and-go

Every component is a whole, pasteable snippet. No re-fiddling padding, alignment, or type — the primitives handle it.

Responsive, for real

Each frame renders at a true viewport width, so media queries fire authentically. Drag any playground to feel the reflow.

Image crop & scale — locked

Deterministic media shapes (hero 3:2→split, program 16:9, thumb 4:3) crop any photo predictably. No layout shift from image size.

All groups live — Cards, Heroes, Lists, Rows, Atoms, Page behavior, Foundations

Every group is built and interactive. Start with Compose a page → to see a full page assembled from kit snippets (your per-session clone template). See KIT.md for composition rules (page order, grid behavior, snippet-drop), BREAKPOINTS.md for thresholds, and GAPS.md for the M3 components that can't be authored as MHC blocks.
