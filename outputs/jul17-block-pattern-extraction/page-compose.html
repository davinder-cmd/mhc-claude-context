How to reuse

1. Copy frame-page.html as your page starting point (or an empty .shell > .shell__rail).
2. Reorder / add / remove blocks — grab each snippet from its component page's Markup section.
3. For CKEditor, keep the {{formula.*}} tokens; for a static mock, swap in real values.
4. Never add page CSS — if a size or spacing looks off, it belongs in mhc-home.css (CodeMirror), not the page.
See KIT.md for the full composition recipe and grid table.
