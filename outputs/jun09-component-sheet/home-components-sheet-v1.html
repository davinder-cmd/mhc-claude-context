Home page · component sheet

Every component built for the home page redesign, in one place. Each section shows the rendered component, a copy-pasteable HTML source snippet, and notes on variants and usage. Source snippets follow the shadow-DOM fragment authoring style — drop them into the admin's editor and they render correctly behind any host page that loads the shared stylesheet (or that injects the component into a shadow root).

Notes

Greeting

Personalized hello, today's date, and quick access to messages and search. Sits between the top bar and the hero. The greeting copy (Hi Davinder) is templated; the time-of-day variant (Good morning, Davinder) is an alternative tone if clients prefer.

HTML source

Notes

  • The red badge on the mail icon (.mhc-icon-btn__badge) shows when there are unread messages. Remove the span when there are none.
  • The icons use Font Awesome fa-envelope (U+F0E0) and fa-magnifying-glass (U+F002).
03 / 10

Hero

Featured program / recommendation. Image fills the left half (locked 3:2 aspect ratio on desktop per design rules); content fills the right half. On mobile it stacks vertically. This is the single biggest visual on the home page.

HTML source

Notes

  • The art panel uses a CSS gradient placeholder. Replace with a real <img> tag (with explicit width/height/alt) when production photography is delivered.
  • Three meaningful state variants exist: standard (start a new program — the version shown), in-progress (replace the CTA with a progress bar), and zero-state (welcome card for brand-new users). Today's snippet covers the standard case; the other states use the same shell with different body content.

05 / 10

This Week — tracker grid

Four tracker tiles — steps, sleep, calories, active minutes. Reads as a weekly summary, not a real-time dashboard. Each tile has an icon, label, value, and trend indicator.

HTML source

Notes

  • 4 columns on desktop, 2 columns on mobile via media query.
  • Trend uses Font Awesome fa-arrow-up (U+F062). Add .mhc-tracker__trend--down to flip color to red and use fa-arrow-down (U+F063) for declining metrics.
  • Icon glyphs: steps fa-person-walking (U+F554), sleep fa-moon (U+F186), calories fa-fire (U+F06D), active min fa-stopwatch (U+F2F2).
06 / 10

Insight banner

Periodic AI-style insight surfaced based on the user's data. Light blue tone visually separates it from generic content. The refresh button cycles to the next available insight (handled by the host page).

HTML source

Notes

  • Icon uses Font Awesome fa-star (U+F005) as a stand-in for the "auto_awesome" sparkle. Worth a review with whoever owns the icon vocabulary.
  • Color tones (--insight-bg, --insight-border, --insight-dot) are pre-defined; don't restyle inline.
07 / 10

Programs — Keep going

Up to three active programs the user has started. Each card has a cover image, title, day-counter, and a progress bar showing % through the program. Tap-target is the whole card.

HTML source

Notes

  • Replace the gradient placeholder in .mhc-program__cover with a real <img> for each program when imagery is available.
  • The progress fill width is set inline as style="width: 45%". This is the one place inline style is needed because the value is data-driven.
  • If the user has < 3 active programs, the grid collapses naturally — show only the cards that exist.
08 / 10

Challenge banner

Active company-wide or team challenge. Single banner shows trophy icon, challenge name, and current standing. Tapping drills into the full challenge view.

HTML source

Notes

  • Icon uses Font Awesome fa-trophy (U+F091).
  • If multiple challenges are active, show only the most recently engaged-with one here — drill-in surfaces the rest. Don't stack multiple challenge banners on home.

Rewards banner

Single-reward-type banner. Shown sample is the Direct rewards / multi-action with $ progress variant. The full set of 12 variants (4 reward types × 3 angles) lives in the jun09 ideation file; this section just embeds the one most likely to ship as the default.

HTML source

Notes

  • This replaces the prior 3-card multi-reward block. The product direction is: one reward type per page, picked per-employer or per-precedence-rule (open question).
  • Icon disc colour swaps per reward type: gift (Direct), olive (Raffle), navy (Points), orange (Store). Add .mhc-reward-banner__disc--raffle etc. when expanding to the other types.
