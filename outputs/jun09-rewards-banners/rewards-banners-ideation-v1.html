Single-reward banners — ideation v1

Twelve banner variants (4 reward types × 3 variants each) for the new rewards row. Each variant is shown at both desktop width (~700px+) and mobile width (360px) via container queries — same banner, different container size. The banners sit immediately below the interest/employer pair row and above This Week.

Each banner fills the row at any width without looking empty. Drag the page narrower than 600px to see how the desktop frame collapses too — both render the same final state.

Type 1

Direct rewards

Take action, get a tangible thing — gift card, paycheck credit, HSA credit, reimbursement. Can be one action (HRA / assessment) or many actions (weekly check-ins, program milestones). Progress maps to either actions completed or dollars earned.

Type 2

Raffles

Earn entries; entries get drawn for a prize. Usually uncapped, so traditional progress doesn't apply. Three angles: lead with entries (most common), lead with the prize, or treat the cap as the progress when one exists.

Type 4

Store credit

Earn credit, spend in the internal store. Progress doesn't have an obvious shape because spend is open-ended. Three angles: lead with a featured item that anchors what credit is for, treat a quarterly cap as the progress, or just hero the balance and let the user shop.
