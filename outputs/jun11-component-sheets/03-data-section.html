Data section · variants

The "This week" tracker grid. Four tiles on desktop (steps, sleep, calories, active min), each with a ring-style icon, label, value, and a sub line ("78% of weekly goal" or "Set a goal →"). Variants cover the meaningful per-tile states.

View in Figma

Per-tile variants

Each tile is the same shell — ring icon at top, eyebrow label, big value with optional trend arrow, sub line. The variants cover which copy/state lives in the sub-line slot.

  • With trend & % to goal — green up-arrow next to the value, "78% of weekly goal" sub line. Default healthy state.
  • Set a goal — no trend arrow, sub line becomes a link Set a goal →. Used when the user hasn't configured a goal for that metric.
  • No data / not synced — value reads "—" or empty, sub line reads "Sync to see" or similar.
  • Trending down — red down-arrow, "X% below your average" — used for metrics where a drop matters (sleep, active min).
  • At goal — solid filled ring icon, sub line "Goal hit 🎯" or similar achievement copy.

Notes

  • Four tiles on desktop, 2×2 grid on mobile (see sheet 05).
  • Icon glyphs: steps &#xf554;, sleep &#xf186;, calories &#xf06d;, active min &#xf2f2;.
  • Trend up &#xf062; (green), trend down &#xf063; (red — add the .tracker__trend--down modifier).
  • The whole tile is tappable via the stretched .tracker__link — drill into the per-metric history.
  • If NO trackers have data at all, swap the entire section for the Empty Data variant — see sheet 04.
