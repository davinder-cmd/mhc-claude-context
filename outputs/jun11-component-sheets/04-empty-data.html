Empty data · variants

What replaces the tracker grid when there's no data to show. Covers the cases where the user hasn't connected a source, the source is connected but hasn't synced, or the sync errored. The empty-state shell takes the same row space as the tracker grid.

View in Figma

Variants

  • No source connected — primary action Connect a source. Body explains what connecting unlocks ("Add Apple Health, Fitbit, Garmin to see your trends").
  • Source connected, no data yet — friendly waiting state. Body reads "Sync is in progress" or "Open your app on your phone to start syncing." No primary CTA, just a passive Refresh link.
  • Sync error — alert tone (warning color). Body explains the error briefly. Primary CTA Reconnect or Troubleshoot.
  • Partial data — some metrics have data, others don't. Mixed state shown as the tracker grid with empty tiles for missing metrics (covered by the regular Data Section variants — sheet 03).

Notes

  • Empty data replaces the full .trackers block, not a single tile. If you have one tile missing, use the per-tile "No data" variant from sheet 03 instead.
  • The container styling (bordered card, padding, rounded corners) matches the tracker grid's outer container so the page layout doesn't shift visually between states.
  • Icon for the empty state is illustrative (a generic chart or sync glyph), not a metric-specific one.
  • This component isn't yet in the jun11 fragment — when added, it goes between the section head ("This week") and the next section. The "This week" head can stay since the empty state still belongs to the data section.
