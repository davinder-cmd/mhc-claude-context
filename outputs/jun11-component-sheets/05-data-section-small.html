Data section · small form variants

Mobile layout of the "This week" tracker grid. Same primitives as the desktop version (sheet 03) — same icons, same value formatting, same trend indicators — collapsed into a 2×2 grid so all four metrics stay visible without horizontal scroll.

View in Figma

Variants

  • 2×2 grid · all data — Steps + Sleep on top row, Calories + Active min on bottom. Each tile keeps its trend arrow and the "78% of weekly goal" sub.
  • 2×2 grid · mixed states — some tiles with data, some with Set a goal →. Mirrors the desktop per-tile variant logic.
  • 2×2 grid · no data on one — value reads "—" with sub line "Sync to see" for the missing metric.

Implementation

Same .tracker markup as desktop (sheet 03). The grid switches via CSS:

CSS — already in the jun11 fragments 
.trackers {
  display: grid;
  gap: var(--s-04);
  grid-template-columns: repeat(2, 1fr);  /* mobile default */
}
@media (min-width: 600px) {
  .trackers { grid-template-columns: repeat(4, 1fr); }  /* desktop */
}

Notes

  • No separate component — just the same .tracker + responsive grid.
  • Touch-target requirement: each tile is > 44 × 44 px. At 2×2 on a 375-px viewport, each tile is ~170 × 110 px including padding. Comfortable.
  • The section head ("This week" + "All Data" link + "Apple Health · 4m ago" sub line) stays the same — it's a single-line head that stacks naturally if the link wraps.
