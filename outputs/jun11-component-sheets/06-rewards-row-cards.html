Rewards row cards · large + small form

The full primitive library for the single-reward banner. Same shell (icon disc · label chip + hero number · attribute · optional progress · optional action). What changes per variant is which primitives are present and what's emphasized — balance vs earnable, with bar vs dots vs levels vs nothing. Both desktop and mobile forms shown.

View in Figma

Variants

Twelve cells in two columns — large form (1432-px desktop) on the left, small form (360-px mobile) on the right. Three hero formats × four progress / no-progress combinations.

  • Hero · "X earned" — "12 earned" + attribute. The natural form for counts (entries, activities, points).
  • Hero · "X" — just the number ("12") inline with attribute. Compact, no big-number emphasis.
  • Hero · long sentence — "$25 earned of $100 this quarter" — single-line description carries the value and the context together.
  • Progress · bar — single solid bar, percent-filled. Default for capped or quarterly-period rewards.
  • Progress · dots — 10 small dots, filled = done. Best for discrete activity-count rewards.
  • Progress · levels — 4-tier ladder with checkmark on completed tiers. Signature for Points & levels rewards.
  • No progress — strip the progress entirely. For balance-only displays, ready-to-spend store credit, or single-action HRA rewards.

Canonical HTML — current jun11 (Points & levels · balance + bar)

The fragment shipping today uses the Points & levels balance + bar variant from this library:

Source — drop into shadow root 
<section class="section" aria-labelledby="rewards-title">
  <div class="section-head">
    <h2 id="rewards-title" class="heading-6">Your rewards</h2>
    <a class="btn btn-text" href="/rewards">Reward Dashboard</a>
  </div>

  <div class="reward-banner">
    <div class="banner-icon banner-icon--rewards">
      <span class="fa-icon" aria-hidden="true">&#xf5a2;</span>
    </div>
    <div class="reward-banner__body">
      <span class="tier-chip tier-chip--silver">Silver tier</span>
      <div class="reward-banner__balance">
        <span class="heading-5 reward-banner__hero">1,250</span>
        <span class="body-3 ink-soft">points balance &middot; 750 to Gold</span>

      <div class="progress" aria-hidden="true">
        <div class="progress__fill" style="--p:62%"></div>

  </div>
</section>

Notes

  • Icon disc is 56 × 56 px with a 26-px glyph. Hidden on mobile (.reward-banner .banner-icon { display: none }) to save horizontal width.
  • Desktop padding: var(--s-06) (32 px). Mobile padding: 20 px.
  • Vertical body gap: var(--s-04) (16 px) between the tier chip, balance row, and progress bar.
  • For non-Points reward types (Direct, Raffle, Store credit), swap the chip, hero number, attribute, progress flavor, and CTA — see sheet 07 for in-context examples.
  • "Redeem" button uses the existing .btn-outlined — no new button class needed.
