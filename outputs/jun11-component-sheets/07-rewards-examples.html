Rewards · examples in context

Worked examples of the single-reward banner across all four reward types — Direct rewards, Raffles, Points & levels, Store credit — and both framings (balance-focused vs earnable-focused). Each row pairs the large form with the small form so you can see how the same banner adapts.

Scenarios

Each scenario is built from the same primitives library (see sheet 06). What varies is which primitives are present and what they emphasize.

  • Direct rewards — D1 multi-action balance + bar, D2 balance + dots, D3 balance no progress, D4 multi-action earnable + bar, D5 HSA reward gated/locked, D6 premium discount active, D7 single-action HRA one-time.
  • Raffles — R1 uncapped balance no progress, R2 capped balance + bar, R3 capped earnable + bar, R4 prize-led (hero is the top prize).
  • Points & levels — P1 balance + levels (tier ladder), P2 balance + bar, P3 earnable to next tier + bar, P4 balance no progress.
  • Store credit — S1 balance "ready to spend" no progress, S2 capped quarterly balance + bar, S3 capped quarterly earnable + bar.

Chip vs attribute logic

Every banner uses two chip slots and one attribute line. The split between them is consistent across all reward types:

  • Chip 1 — program/category. Slow-changing identity (e.g., WELLNESS REWARDS, SPRING RAFFLE, POINTS, STORE CREDIT, HSA REWARD).
  • Chip 2 — period/scope/status. The bucket the value belongs to (e.g., Q2 2026, CAPPED AT 50, SILVER TIER, LOCKED, ACTIVE).
  • Attribute line — the math. Dynamic context for the hero number — the rate, the gap, the timeline, the next milestone. Examples: "of $250 this quarter · earn $25 per check-in", "38 still to earn · 12 of 50 earned so far · draws May 31", "750 pts to Gold · earn 50 pts per workout".
