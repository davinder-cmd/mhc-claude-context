Rewards display · variations v2 · actions & lozenges

Six more variations, building from the Healthy Habits action-tile pattern. Borrows the check-circle + reward-inline pattern, explores lozenge/pill compositions for the multi-type rewards, and tries a single-reward hero with a dashboard link to the rest. Same v6 warm-neutral + SF Pro foundation.

V6

Earnable actions (habits-pattern adapted)

Borrows the Healthy Habits structure exactly — but the tiles are actions that earn rewards, not habits. Check-circle on the left, action name middle, reward inline on the right. Footer shows total available today + current balance + dashboard link. Tests: does framing rewards as "what you can do today to earn" beat showing the static balance?

What it adds

Behavioral pull. Shifts the frame from "look at what you have" to "here's what you can do right now." Pairs with the dollar-equivalent reward economy — every tile is a discrete earning moment with a known payoff.

Risks

Shifts the section from passive (display) to active (do). Members may expect the actions to be smartly chosen by the priority engine; if they're random, this lands as nagging. Static balance still has to live somewhere — here it's a small line in the footer.

V7

Hero point balance + dashboard link

Show one prominent reward — points + tier + progress — and a quiet message about the rest ("Also earned: $75 gift card · 12 raffle entries · $25 store credit"). Pushes the multi-type complexity off home and onto a dashboard. Tests: does focusing one number drive more engagement than showing all four?

What it adds

Singular focus. One number readers latch onto, with a concrete next milestone (Gold tier) and a progress bar. Multi-type still acknowledged but shipped to a dashboard — keeps the home page calm.

Risks

Buries the configurability moat. Multi-type rewards being visible on home is one of the v2 inventory's named differentiators. Putting them behind a click weakens that. Also makes points feel like the "main" reward — for clients with rich gift-card economies, that's a reframing.

V8

Lozenge row (single horizontal line)

All four reward types as compact horizontal pills — icon + label + value — wrapping if needed. Small, tactile, glanceable. Each lozenge is a tap target into the dashboard for that type. Tests: at scannable scale, does the "four currencies" story still land?

What it adds

Most compact summary on the page. Reads in one line on desktop. All four types still shown so the multi-type story holds. Lozenge shape is naturally tappable and low-density.

Pills mix four chromatic families (warm + primary + lavender + moss) — same chromatic-budget concern as V2 (color wash) but more permissive because the pills are smaller. Less prominence overall — rewards becomes a "footer-y" surface, which may not match its strategic weight for some clients.

Combines V8 (top: lozenge balance row) with V6 (bottom: earnable actions). Top says where you stand; bottom says what you can do today. The fullest expression of the rewards section as a behavioral surface.

V10

Total value hero + lozenge breakdown

Lead with the dollar-equivalent total across all reward types. "$200 in rewards" reads as a single number a member can talk about. Lozenges below break it down. Connects to the v1 "dollar-equivalent rewards framing" rationale — the differentiator vs. Personify's raw point counts.

What it adds

The dollar number is the headline a member remembers. Connects directly to the differentiator note from the original three-lane spine wireframe ("$75 earned · $25 to next gift card" beats "5,200 / 10,000 points"). Lozenge breakdown preserves the multi-type story.

Risks

Computing a total dollar value across types means converting points and raffle entries to dollars — that math has to be defensible and stable across clients. If the conversion is opaque or off, the total reads dishonest. May also overstate value if clients have many points but few cash-out options.

V11

Earning velocity (gamification frame)

Frames rewards around momentum, not balance. Three velocity stats — streak (warm), this week (moss), today's available (primary) — each with an icon. Below: the action tiles. Static balance shrinks to a single footer line + dashboard link. Tests: does an earning-frame outpull a balance-frame for daily-return engagement?

What it adds

Strongest behavioral surface. Streak + this-week + today-available together build a sense of compounding momentum. Static balance is shipped to the footer line — it's still there, just no longer the headline.

Risks

Gamification can read juvenile if not handled carefully — stars and streaks need to feel earned, not performative. Balance gets the smallest treatment of any variation; clients who lead sales with the multi-type configurability moat may push back. Streak logic also has to handle gracefully if a member misses a day.
