Pair block — no-employer state · grouping options

When there is no employer message, both cards are interest-based. Same two-card layout, but one header (“Based on your interests”) and one footer (“See more like this”). Six treatments for binding the two cards into one cohesive group. Each is shown at desktop (side-by-side) and mobile 375 (stacked) via container queries — the transition you care about. Footer actions: “See more like this” + “Edit interests”.

A · One contained card, rows split by a divider

The whole thing is a single card. On desktop the two items sit side-by-side with a vertical hairline between them; on mobile they stack with a horizontal hairline. Header inside the top, footer inside the bottom. Maximum containment — it reads as one object.
