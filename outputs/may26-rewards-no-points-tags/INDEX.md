# Rewards — no-points card · tag treatments

The tighter no-points rewards card (no progress bar, no points pill) — just a heading, subline, and reward-type tags. Carries up to 4 reward types: **4×1 on web, 2×2 on mobile** (container-query reflow).

- **Heading:** "Your healthy choices are paying off"
- **Subline:** "Every program, goal, and challenge adds to your rewards."
- **Tags:** 🎁 gift card · 🎟 raffle entries · 🛍 store credit · 💳 prepaid (4th, to exercise the 4-up grid)

## Versions

- **v1** — `rewards-no-points-tags-v1.html` — 6 tag treatments, each shown web (4×1) + mobile (2×2).

## The 6 treatments

| # | Treatment | Notes |
|---|-----------|-------|
| 1 | Soft pill · icon + value | Tightest, smallest numbers, icon carries the type |
| 2 | Soft pill · icon + value + label | Adds a tiny type label under the value |
| 3 | Bordered mini-card | Outlined card, icon-top — more substantial / tappable |
| 4 | Tinted-per-type cards | Color-codes each type (gift/raffle/store/prepaid) |
| 5 | Outline chips | Hairline only, lightest weight, smallest numbers |
| 6 | Icon-led horizontal cards | Round icon badge + value/label — premium "accounts" feel |
